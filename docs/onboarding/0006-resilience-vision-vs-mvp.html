Resilience — Vision vs. MVP

The single biggest brain-rot trap in this repo: the docs describe resilience your live system doesn't have. Today you learn to tell the map from the territory. ~13 min.

2 · How to tell live from legacy (the durable skill)

live = services/{edge,gateway,collector} + packages/shared. legacy = legacy/, frozen, reference-only (ADR-0015). A tell: CLAUDE.md's "Directory Structure" shows src/index.ts with Bun.serve — that's the legacy layout, not services/gateway/src/server.ts. When the docs and the code disagree, the code in services/ wins.

3 · The three features that live only in legacy (your port targets)

① Circuit breaker legacy/services/circuit-breaker.ts

Redis-backed Lua state machine, per-deployment:

CLOSED ──5 failures──► OPEN ▲ │ 30s │ 1 success ▼ └────────────── HALF_OPEN (probe)

Stops cascading failure: an OPEN breaker fails fast instead of hammering a dead deployment.

② Retry + backoff legacy/services/retry.ts

  • Exponential: 1s · 2s · 4s · 8s, capped 30s
  • ±1s jitter (avoid thundering herd)
  • Respects Retry-After header
  • Non-retryable: 400, 401, 403 (don't retry client errors)
  • Max 3 retries

③ Streaming usage interception legacy/utils/streaming.ts

A TransformStream that passes SSE chunks through to the client while sniffing the usage for billing — OpenAI's usage in the final chunk, Anthropic's message_delta. This is what makes streaming responses billable. The MVP's buffer-and-dump can't do this live.

6 · Strength & weakness (mission lens)

Strength

The live proxy is honest and tiny — one HTTPS fetch, easy to audit, fail-closed on the one unsupported case (bridge+stream → 400). And you're not inventing resilience from scratch: legacy/ holds battle-tested breaker/retry/streaming with tests to port. The architecture (per-deployment fallback chains in the model registry) is designed for a breaker.

Weakness / debt

Today a flaky Azure deployment is not retried, a dead one is hammered (no breaker → cascading failure), streaming is faked, and failed upstream calls leak budget until TTL. Worse, the docs claim otherwise — the most dangerous gap, because it hides the others. Fix the docs and the code.
