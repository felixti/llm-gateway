LLM Gateway — Glossary

The ubiquitous language. Adhere to these exact terms in every lesson. v1 · 2026-06-17

Planes & topology

Edge plane .NET 10 · YARP
services/edge. Generic identity/transport governance: validate the Entra user token, mint OBO, per-principal RPM, route. Why a separate plane: Microsoft.Identity.Web does Entra validation/OBO better than a hand-rolled verifier (ADR-0009).
LLM-domain plane Node 24 · Hono
services/gateway. LLM-specific governance: USD budget, token-aware TPM, guardrails/PII, provider resilience, FinOps. Needs tiktoken/pricing/protocol parsing — can't live in .NET without re-implementing all of it (ADR-0009 SP-C rejected).
Edge, not execution plane ADR-0008
Foundational principle: the gateway governs ingress/egress (auth, meter, guard, route) and never executes the caller's work — no server-side tool/MCP exec, no agentic loop. Executing = inheriting sandbox, SSRF, budget runaway: a far bigger, riskier system.
Envoy ingress
k8s ingress (full vision). TLS terminate, global/per-IP rate-limit, network WAF, route to YARP. Does no authN (identity stays solely in YARP).
Collector
services/collector, Node 24. Drains the usage queue, batches, writes to ADX.

Trust & identity

Per-hop M2M token
YARP authenticates to the gateway with its own Entra client-credentials token (aud=api://llm-gateway-internal). The gateway accepts only YARP's exact appid/azp. Operator refused mTLS; this is the trust anchor instead (ADR-0009).
Forwarded claims
YARP strips client-supplied X-Principal-* headers and sets its own after validating the user token. Gateway trusts them because the hop is gated by YARP's M2M token. Headers: X-Principal-Id / -Kind / -Project / -Scopes.
Header-spoofing control
The new top security risk in a two-plane split. Mitigations: NetworkPolicy (gateway accepts ingress only from YARP), M2M appid pin, header hygiene (reject duplicate/case-variant X-Principal-*), optional JWS-signed claim set.
OBO (On-Behalf-Of)
YARP exchanges the user token for a downstream token to call the KB Service as the user. KB enforces per-user ACL. Gateway (Node) is not in the KB path.

Stores (MVP — no PostgreSQL)

Azure Table Storage ADR-0011
Authoritative config/policy store: budget caps, model allowlists. Synced into Redis.
Azure Managed Redis (cluster) ADR-0013
Fast path: budget reserve/spent, RPM/TPM counters, circuit-breaker state. Atomic via Lua.
Storage Queue → Collector → ADX ADR-0012
Usage metering pipeline. Async, decoupled from the request path.
WAL (Write-Ahead Log)
Disk DLQ (0600 files in 0700 dir). Last-resort durability when both Queue and Redis fail. Replayer drains it later.

LLM-domain mechanics

Budget reserve (Lua)
Atomic check-and-reserve in one Redis round-trip: validate cap, increment reserved, set TTL reservation. 1.2× multiplier; 300s TTL for orphan cleanup.
Protocol guard
Validates model ↔ endpoint compatibility before proxying (e.g. Claude model on /v1/messages).
Streaming usage intercept
TransformStream passes chunks through while extracting final usage (OpenAI: last chunk; Anthropic: message_delta) for billing.
Responses↔chat bridge
Translates Chat Completions ⇄ Responses API for codex models.
Circuit breaker
Per-deployment: CLOSED → OPEN (5 fails) → HALF_OPEN (30s) → CLOSED (1 success).
